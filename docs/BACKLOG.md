# Auto Git Backlog

Backlog 保存尚未进入当前 Sprint 的候选能力。进入实现前必须升级为 Task、Spec 和 Plan。

## Local Core

- 多仓库与嵌套仓库边界。
- 自动迁移脏改动与高级冲突辅助；
- 大型 monorepo 的增量状态和性能优化。

## Agent Skill

- 更多 Codex、Claude Code 和其他 Agent 原生适配；
- 团队级策略与可共享教学偏好。
- 基于真实需求评估独立 CLI 分发；
- 多客户端共享、后台服务或远程执行出现后再评估 MCP Adapter。

## Remote 与 CI

- GitLab/Gitee 专用账号、仓库创建与 Release adapter；
- PR、review 和 merge；
- PyPI、npm、容器 Registry 和应用商店发布；
- GitHub Actions 与通用 CI 模板；
- 本地回归和 CI 结果对账。

## Git 训练营

- 沙盒仓库与可恢复练习；
- 分支、合并、冲突、Worktree、回退和协作课程；
- Agent 边做边解释；
- 错误注入与安全恢复练习；
- 学习进度和能力地图。

## 跨项目集成

- ANK 可选推荐与项目初始化配置；
- Skill Engineering 仓库作为普通项目的 Auto Git 验证；
- 普通代码工程；
- 内容工程和非代码文件版本管理；
- Agent Skill 项目公开包与私有工程双仓发布。

## 明确延后

- 后台监控所有用户目录；
- 无审批自动公开发布；
- 凭证托管；
- 云端 SaaS、团队 RBAC 和托管策略中心；
- 用 Auto Git 替代 Git 本身。
