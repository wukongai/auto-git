# Superpowers

`superpowers/` stores structured agent work products: specs, plans, designs, testing, handoffs, mockups, and brainstorming. These are the documents agents should read before starting feature-level work.

## Rules

- `specs/`: what should exist and why.
- `plans/`: how to implement it safely.
- `designs/`: product, interaction, visual, and workflow design options.
- `testing/`: test plans, cases, and verification reports.
- `handoff/`: what the next session or agent must know.
- `mockups/`: feature-specific visual prototypes.
- `brainstorming/`: structured option generation before committing to a plan.

Feature-level work should normally create or update at least one spec and one plan. UI/UX work should add a design artifact. Risky work should add a test plan. Long-running work should leave a handoff before stopping.
