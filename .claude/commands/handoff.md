# Handoff

1. Create or update `docs/superpowers/handoff/YYYY-MM-DD-<topic>-handoff.md`.
2. Include:

   - commands run
   - verification result
   - known risks
   - exact next steps
3. Update daily log or sprint if relevant.
4. Do not claim completion unless docs and verification are aligned.
